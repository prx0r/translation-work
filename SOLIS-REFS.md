# SOLIS-REFS — which plate for which parable (selection law)

*22 plates = 22 operations. The seal's parable has an arc; the plate
must have the SAME arc. Ref carries style IMPLICITLY — the prompt never
says "make it Solis" (that instruction is what made tech-seal-solis
look AI). Ref + seal-text only, like v4.*

## Method (per parable)
1. **Arc-match (decides):** name the parable's operation (bondage→release,
   teaching→answer, recognition, purification, coronation...) → pick the
   plate whose scene IS that operation.
2. **Structure:** bordered page > cropped miniature (borders are the
   commentary layer; cropped plates are content-only).
3. **Quality:** hi-res, vibrant, clean (watermark ok if output didn't
   leak it — v4 proved user1 didn't).
4. **Unspent:** one plate per seal, never reuse a plate for another
   seal of the same work. Log plate + seed in P1.

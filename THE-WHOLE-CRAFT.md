## 3. HOW TO DO IT WELL (the playbook, each with proof-file)
1. **Read the layers as clues.** L4 gives the imagery verbatim
   (spanda: "serpent-coiled… straight as a staff"; ptvm: "fruiting
   at once"; sakt: pomegranate-bulb) — the nature-first answer is
   usually IN a couplet. Proof: SAKT-CANONICAL, SPAN-NATURE-v2.
2. **Door-title first.** Name the impossible natural thing flatly;
   the reader's "wait — where?" supplies the awe (svab: "the land
   where the sun never sets"). Proof: SVAB file + Round-6 law.
3. **One-line test before drafting.** Child states the core in one
   plain sentence after ONE hearing (spider: "she spun herself
   into knots, then spun herself to freedom"). Fail = rewrite.
   Proof: ghatakarpara one-liners in P1-INDEX.
4. **Animals/nature/folk over institutions** — hive, storm, shore,
   garland, garden. BUT the creature encodes the technicals, never
   evicts them (deha keeps temple+six-senses+quiver; every count
   told-or-mapped). Proof: DEHA + TECHNICAL-FIDELITY law.
5. **Mechanics performed, not glossed.** If cutting a doctrine
   stops the story, it's embedded (mpa: gifts sink, self-figure
   sinks, everything stands). Gloss = someone SAYS the teaching
   (pancashloki's traveler). Repairs applied: bodha (release-as-
   crossing), bhuv (boons-as-stage-acts), ajada (grant-as-shadows-
   nod), anubh (dew-before-asking).
6. **Plain words inside, doctrine in the map.** No liturgical
   coinage in the tale ("shrine-dust" → "old junk"; mātṛkā → the
   alphabet; sense-goddesses → his eyes and hands with presents).
7. **The P1 rig, every time** (the s04 exemplar):
   seal-statement (one sentence) → zone table (element|verse|
   argmap-step|rasa-job, DOUBLE-ANCHOR or cut) → colour cipher from
   C1 rasa (every colour cited) → composition laws (one subject,
   no letters, no roundels/template, zone-continuity) → base stage-
   match + spent-log + seed → prompt = SEAL TEXT ONLY (implicit
   style: reference carries the Solis; materials-vocabulary allowed)
   → ticked anti-mistake checklist.
8. **Hermetic clues** in every seal: 4–6 border-medallions, each
   double-anchored (banyan-seed=v24, crossed-lamp=v26, flame-no-
   shadow=ajada). The frame tells what the plate can't.
9. **Embedding audit** (M/E/G table) before the owner sees it —
   propose repairs yourself (PARABLEVIDEO EMBEDDING AUDIT).
10. **Self-grade vs the benchmark** (spider=9.5, ghatakarpara=9.4)
    and rate honestly BEFORE showing. Ratings table: PARABLEREGISTRY.
11. **Show-don't-tell in seals too**: mid-act freeze (pour-frozen,
    foot mid-press), two-way geometry (matter-down/light-up in mpa),
    absence-as-content (blank center = sivasutra, empty canvas =
    parc).
12. **Voice layer**: tags per damn guide (max 3, one emotion,
    pauses do the work), rasa→direction, `damn/fish/validate.py`
    PASS before any spend; granny LOCKED (614f8afd…); worker
    /api/read via playwright = $0 path; NEVER render without
    explicit owner yes. Files: voice-scripts/*.tagged.txt.
13. **Art standards**: final snapshot (freedom not struggle) ·
    rasa-as-gradient (dark base → light crown) · composition
    = story (spider: web→thread→sun) · review gate against the
    parable BEFORE showing (v1 caught live) · white-normalize
    (v≥200→255) · seed+prompt logged · print = exact 5:7 compose
    with ivory margins.
14. **Queue discipline**: shortest-first in PARABLEREGISTRY;
    batch rule (ALL scripts → owner confirm → media); seeds
    801–843+ logged in P1-INDEX; spent-bases never reused; pulls
    by single-file polite requests (Wikimedia 429s on bulk).

## 4. HOW NOT TO DO IT (the mistakes, each = a law)
1. **Translated from L2 first** → missed gahanād ("heart-caves").
   LAW: Sanskrit first, cite→T1→L0→argmap→L2→C1 (literal skill).
2. **Metaphors in literal** ("rock caves") → resolve tiers: stack
   says it / stable-background visible-compound / keep bare.
3. **Pageant parables** (song-4's first draft: 9 beats, a cast) →
   tortoise-bar: one essence, ≤2 characters, one image, one turn.
4. **Scripting voices INTO the text** (granny/kid dialogue tags in
   parables) → voices are a production layer; story = third-
   person narrative (s02/s03 re-told later).
5. **Over-specified P1s** (named roundels, "keep the border",
   template parts) → template-AI-look, lost the web (v2). LAW:
   LESS IS BETTER — reference carries style, prompt carries seal.
6. **Prompt replaced an image-act** (v2: "one thread" instead of
   the web) → middle zone died. LAW: all zones physically present,
   connected.
7. **Duplicate subjects** (spider echoed into roundel) → exactly
   one subject.
8. **Two-step style-restyle** ("transform into Solis treatment") →
   AI-look. LAW: implicit style, ONE step, base does styling.
9. **Cross-text leaks**: parapraveśikā's proof-retired + ten-
   trumpets smuggled into paryanta ideas → caught by the double-
   anchor audit. LAW: a great line never crosses works.
10. **Liturgical coinages** ("shrine-dust", "altar of refusals")
    → the ONE-LINE law + real-world nouns.
11. **Weak door-titles** ("crew that builds the world nightly" —
    owner: "shit") vs "sun never sets" → title must make you step
    IN (Round-6).
12. **Institution frames** (census, workshop, bathhouse, estate-
   office) → all rated ≤6.8; natural frames ≥7.5. paryanta redone
    twice (5.8 → v3 still-sea "beautiful").
13. **Explaining figures** (pancashloki's traveler lectures) →
    show-don't-tell; door-brightens re-angle drafted, pending.
14. **Gloss-middles** (kram litany, bhuv told-boons, bodha spoken-
    release) → EMBEDDING AUDIT; repairs applied to four lines.
15. **Density over cap** (siva450 folds = essence-translation;
    90s at 450v) → fold-flags mandatory; owner deferred siva450.
16. **Renders before asking** — never happened (guard held), but
    the LAW: no seed fired, no base pulled, no audio until explicit
    owner yes (voice-scripts stand validated-and-waiting).
17. **Wikimedia bulk-crawl 429** → bounded lists, 3–5s delays,
    single-file pulls; 21/110 on disk, rest cooldown.
18. **Print compose bug** (edge-sampled colour → black bars) →
    fixed PAPER-constant + exact-ratio compose (305dpi verified).
19. **Background renders killed** (even setsid) → foreground with
    long timeout (92s etch = ~2.4 min).
20. **Worker /api/read 403 from bare urllib** (CF bot-block) →
    playwright browser path; stitches via ffmpeg; $0.
21. **Lost parables in chat** (s02/s03/s12 never filed) →
    recovered; LAW: every approved artifact lands in a FILE same
    session (P1-INDEX caught it).
22. **Base/seed collisions** (plate #1 twice; spent-log in three
    files) → P1-INDEX = single source; SOLIS-REFS superseded note.
23. **Data oddity panic** (sivasutra/span-prefixes) → verify before
    judging: it was correct vṛtti-expansion content.

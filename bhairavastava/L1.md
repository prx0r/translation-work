# Bhairavastava — L1 controlled

## bh-p01 (1)
Pervading-the-particular-states-of-moving-and-unmoving, consisting-of-consciousness, one, endless, beginningless; Bhairava-Lord, refuge of the helpless, by mind-become-Yours, in heart I venerate. // abhts_1

## bh-p02 (2)
Become-of-You, this, without-remainder, now, appears, to-me, by-power-of-Your-grace; You, Maheśa, always my self; by You all is mine. // abhts_2

## bh-p03 (3)
In-own-self, all-pervading, in-You, as-Lord, therefore, not, of-transmigration-fear-talk, exists; even-though hard-to-bear suffering, delusion, terror-causing in-karma-hosts. // abhts_3

## bh-p04 (4)
O-Ender, toward-me, toward, not, gaze, this, most-wrathful-terrible, direct; by-Śaṅkara-service, contemplation-firm, I-am terrifying-Bhairava-power-filled. // abhts_4

## bh-p05 (5)
Thus, whose-great-darkness-is-dispelled-by-rays-of-world-awareness; Death-Yama-ender-karma-ghosts — Lord, salutation; never I fear. // abhts_5

## bh-p06 (6)
Whose-true-essence-of-world-objects-is-seen-by-rays-of-arisen-true-awakening; in-being-full in You, I, self, bliss I enter. // abhts_6

## bh-p07 (7)
Into-mind's-range, comes, when-indeed, affliction-state, producing-slight-anguish; Lord, then-alone my with-You-nondifference; hymn-supreme-nectar-rain arises. // abhts_7

## bh-p08 (8)
O-Śaṅkara, truly, this, vow-giving-bathing-austerity, dispelling-becoming's-heat; Your-scripture supreme-nectar-contemplation in mind, bliss-stream flows. // abhts_8

## bh-p09 (9)
Dances, sings, rejoices, deeply, consciousness, this, my, O-Bhairava-Lord; You, dear, having-obtained, beautiful-vision alone, hard-to-get-by-others, samaya-knower. // abhts_9

## bh-p10 (10)
In-the-month-of-Pauṣa, on-the-dark-tenth, Abhinavagupta, hymn, this, made; by whom the Lord becomes, world's great-heat pacifies instantly, compassionate. // abhts_10

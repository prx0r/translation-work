# C1 NOTE — bod-p01

Moved from C1 (pristine essence and SUMMARY only):

## SUMMARY

A light that never sets holds brightness and darkness alike; a solitary inward reality, which both bound.

## VOICE MAP

## KEY TERMS

* **anastamita** — unsetting: the verse's whole point (never sets).
* **yadantaḥ** — whose-end: limit and abode both (L2 fidelity).

## CRUXES

## FUNCTION

Form → inhabitant: light-form stated, the One within whom all ends.

## LOCAL CONTEXT

## EXPLANATION

Api includes darkness in the domain; yadantaḥ holds limit and abode together.

# IPVV Vol 1 — Chunk: the memory-error (smṛti-bhrānti) + Bhaṭṭa Śaṅkaranandana — T1

*Kārikā 3 of the memory-analysis: "dṛṣṭālambanatā bhrāntyā tadetadasamañjasam" (the
object-supporting-ness [of memory] by error — this is incoherent). Abhinava's commentary
examines whether memory's object is real, and engages **Bhaṭṭa Śaṅkaranandana** — the Kashmiri
Buddhist epistemologist who argued that memory's object does not appear (artho na bhāsate).*

*Source: M00020 lines 6540–6600. Base: Torella's ĪPK. Max-effort T1.*

---

## The kārikā (3)

> **athātadviṣayatve'pi smṛtestadavasāyataḥ | dṛṣṭālambanatā bhrāntyā tadetadasamañjasam || 3 ||**

> But (atha) — even in the not-that-object-ness (atadviṣayatva) of the memory, [being] by-its-
> settling-in-that (tad-avasāyataḥ): the object-supporting-ness (dṛṣṭālambanatā) by error
> (bhrānti) — this [is] incoherent (asamañjasam). (3)

## The commentary

> **Objection (nanu):** "If the one-object-ness (ekaviṣayatva) of the memory and the
> experience were ultimate (pāramārthika), then, for its establishment, one would exert; but
> [it is] not thus. For — the past father, who, in the recollection, shines: he, then, was
> destroyed; how would he shine in the recollection? As the burnt father neither laughs nor
> scratches, so, [even] shining, he is not — this is the certainty (niścaya). Nor [is there],
> of this [memory], the having-the-two-times-of-the-present-and-the-past, [for] the father,
> from the contradiction (virodha). And, in the acceptance [of that], the wholly-excluded
> silver (sarvato-vyāvṛtta rajata), how [would it], elsewhere too, be many? And that [is] the
> error (bhrama). Nor would that non-lucid (asphuṭa) memory-appearance (smārta-pitrābhāsa),
> [being] not-determined-in-place-time-form, be able to attain the one-ness (ekatā) with the
> experiential-appearance (ānubhavika-ābhāsa), [which is] opposed [to it] by the reverse
> [character]. Thus, in that not-manifesting object, [the memory, being] of the form of the
> mere-conceit (abhimāna-mātra), from its ascertainment (adhyavasāya), [and] being-its-
> illumination (tad-avabhāsikā) — [thus] "the memory [is] of the seen-object (dṛṣṭaviṣayā),"
> [and] is said "by error (bhramavaśāt)" — this [is] the meaning of the three pādas of the
> kārikā, by the summary-exposition (saṃkṣepa-vyākhyā)."

> By "[the memory's] object-supporting-ness... is introduced (avatāritaḥ bhramaḥ)" up to
> "[being] incoherent (ityantena)" — for thus, Bhaṭṭa Śaṅkaranandana, by the direction of the
> memory (smṛti-diśā), refuted the object-ness of manifestation (artha-dharmatāṃ
> prakāśamānatāyā):
>
> "The object does not appear (artho na bhāsate); from the non-fitness (ayoga) of the error
> and the memory (bhrāntismṛti); [and] the being-the-time-of-the-intellect
> (buddhikālatva); nor [is there] the one-ness (ekatā), from the difference-of-place (deśādibheda);
> or, in the truth (tattve), [there is] the cognition-of-the-own-place (nijadeśādi-vedanam)..."

*(the Śaṅkaranandana passage: the object of memory does not appear; the memory is a mere
conceit, not a real object-cognition. Abhinava is engaging the Buddhist's skepticism about
memory's object.)*

---

## T1 apparatus — the key decisions

1. **dṛṣṭālambanatā bhrāntyā → "the object-supporting-ness by error"** — the Buddhist's
   account: memory seems to have an object, but that's an error (the object is gone).
2. **the burnt father example** — the past father, though recollected, cannot appear as real
   (he's destroyed); so memory's object is not a real presence.
3. **the silver (rajata) example** — the illusory silver: if the object were real, the
   "wholly-excluded" silver couldn't be "many" elsewhere — it's a conceit, not a perception.
4. **smṛti = "the memory"** — the recollection; its object-ness is the crux.
5. **Bhaṭṭa Śaṅkaranandana** — the Kashmiri Buddhist epistemologist (the MVV's interlocutor).
   He argues: "the object does not appear (artho na bhāsate)" — memory's object is not manifest;
   the memory is a mere conceit. This is the position Abhinava must refute.
6. **the refutation** — memory's object is not a fresh appearance (the object is gone), but it
   is not a mere conceit either — the memory recollects the prior experience by its impression
   (the saṃskāra), which requires the stable self.

**The crux:** the memory's object. The Buddhist (Śaṅkaranandana) says the object of memory does
not appear (it's a conceit). Abhinava's response (to be developed in the following verses):
memory recollects the prior experience via the impression, not as a fresh appearance — which
requires the stable self. This is the heart of the anti-momentariness argument, and it engages
the specifically Kashmiri Buddhist interlocutor.

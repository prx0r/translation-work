# C1 — isva-p04 (vv. 28–36): potter, helpers, and what will cannot do

## SUMMARY

Without that, no pot without a potter — how else? From clay-lump nature, own-nature watches potters. Entering matter with helpers never arrays — able though they be. Wisdom linked to world-traffic: never without. No will, no wonders — mere gross, never world-good. Rule-marvels only if mere potter-help bore pots. Never bodies otherwise — end-led array excels. Neither Lord nor un-Lord atomically taken — yet need fulfilled. Pradhāna will-less — person-aim-ness stands.

## KEY TERMS

* **kumbhakāra** — potter: without whom no pot (v28).
* **svabhāva/apekṣā** — own-nature/watching: clay watching potters (v29).
* **sahakārin** — helpers: entering, never arraying (v30).
* **cikīrṣā** — will-to-make: without which, grossness (v32).
* **kulālasahakāritva** — mere potter-help: the failed sufficient (v33).
* **arthanīyatva** — end-led-ness: why array excels (v34).
* **aṇulakṣaṇa** — atomic-marked: neither extreme taken as (v35).
* **icchā** — will: pradhāna has none — yet aims stand (v36).

## rasa

Workshop-triumph (vīra): potter, clay, helpers cross-examined — array excels, extremes fenced, aims standing will-less. Wonder (adbhuta) that ends lead.

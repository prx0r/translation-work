# C1 NOTE — isva-p04

Moved from C1 (pristine essence and SUMMARY only):

## SUMMARY

Without that, no pot without a potter — how else? From clay-lump nature, own-nature watches potters. Entering matter with helpers never arrays — able though they be. Wisdom linked to world-traffic: never without. No will, no wonders — mere gross, never world-good. Rule-marvels only if mere potter-help bore pots. Never bodies otherwise — end-led array excels. Neither Lord nor un-Lord atomically taken — yet need fulfilled. Pradhāna will-less — person-aim-ness stands.

# Kramastotra — L1 controlled

## kram-p01 (1)
This hymn is the course of great ease; in the midst of the host of sorrows, the rite of completion, the essence of great bliss flowing, this inauspicious day — constantly, on the worshipper's conduct, reflecting, it reflects back; the mind, fear-gone, in the hymn. // AgKs_1

## kram-p02 (2)
Examining own self, examining again the hymned conduct, so the worshipper in hymn-practice without effort; and examined self, in all-knowable-moment, that thus in hymn I, here, always, without effort. // AgKs_2

## kram-p03 (3)
Ungrasped, own self is never knower of thing-knowledge; ungrasped, own self indeed is not; Śiva is that self, shining, all-thing-one-sap; hence I in hymn with devoted heart always blissful. // AgKs_3

## kram-p04 (4)
By varied birth-etc.-wandering-course-garments, omniscience gained in heart; that inside, teaching-spread-course-become light, clearly in speech obtained, now I hymn without effort. // AgKs_4

## kram-p05 (5)
Shaking off bond-abiding-conceit, enjoying varied things, by great fire of hymn-hutāśana, burned difference; varied self-splendor-rush, drinking things, varada, maddened, blissful. // AgKs_5

## kram-p06 (6)
If Śiva-oneness-gained wish, how hymn? If conduct, by that suddenly Śiva-oneness-first-means. If Śiva-oneness-gained, conduct-abandoning brings expiation. // AgKs_6

## kram-p07 (7)
Vivid flame-formed, shining, burning, then displaying — shedding other of fire, what body indeed is possible? I praise consciousness-rays; if by own-own, by that praised, no other whatsoever becomes Lord's power. // AgKs_7

## kram-p08 (8)
Varied-beginning, in galita-niyama, what rasa, from partlessness fullness unsurpassed unequal; self's light-yoga with all-thing-one-mayatā, by uncontrary dharmas, other-cit anargha-guṇā. // AgKs_8

## kram-p09 (9)
By such forms, varada, varied your body shines; in own-portion this world, difference-gone, Lord's. That same this hymn-to, heart and speech-outer-instrument-bonds would be mine, constant, unabandoned-rush. // AgKs_9

## kram-p10 (10)
Your alone one's inside, shining-mahat-glory, knowledge-ocean's wave-spread rasa, which by-nature; they same these, creation-maintenance-dissolution-formed, simultaneous-shining moon-sun-fire's rise-setting-power-glory. // AgKs_10

## kram-p11 (11)
Hence varied-varied-course-station-other-distinction-etc.-standing-thing-enjoying-power, Lord's power, always goes, no difference how. That in this ground (akula), Bhairava, your pada — that one-pointed become my heart-ground, Bhairava Lord. // AgKs_11

## kram-p12 (12)
In measure, dissolved, Śiva-pada-shining-power-vaibhava-force, body-breath-and-rest limited-made-agentness-standing; when time-condition, dissolution-state approaches you — then goddess, which, shining, my, she be Śiva-made. // AgKs_12

## kram-p13 (13)
Course-rush of it, in earth, making difference-grasping, own-powers, Lord, teach always in own-self; then three-formed (knowledge/action/will) standing-maintenance-dissolution-great-creation-power, become-immersed wishful heart. // AgKs_13

## kram-p14 (14)
Formerly creation dissolved, fire-formed, which there would shine, beyond-rush-facing, moon-touch-lovely; fire-moon-splendor-both-glory, Bhairava Lord, this creation-named, my mind, always shining. // AgKs_14

## kram-p15 (15)
Released, things-portion, outside extreme tasteless, when there you, by rush, raktimayatā; then red goddess, your all-things, indeed me, by action-raktāpāna-course-made gathering, make red. // AgKs_15

## kram-p16 (16)
Outside-conduct abandoning, consciousness-ground dwelling, to dwell, when things-difference showing, waveless, stability-lost; of maintenance dissolution, goddess, your, maintenance-of-saṃsāra, my, always dissolve. // AgKs_16

## kram-p17 (17)
World-dissolution wishing, by own-rush, own-doubt-fear-named procedure then prohibition teaching; Yama created thus, then again doubt dissolving, great-goddess, that my world-fear she dissolve. // AgKs_17

## kram-p18 (18)
Dissolved doubt-mass, instantly, full, Lord, power, all-knowable-host swallowing, by enjoyment-rush, Bhairava, dissolution-named, my heart, difference-portion, strike. // AgKs_18

## kram-p19 (19)
Thus by goddesses, instantly, difference-power melted, thought-life-breath, shining, mother-standing, enough; hence dissolution-portion, own-heart reflected, standing, blissful, she be, goddess, my, death-dissolution-maker. // AgKs_19

## kram-p20 (20)
Thus these three, by own-power-ray-mass-expansion, obtained, six-wheel-course-made, powers these; gradually by unfolding, varied world-state making; from these, goddesses, devoted heart, I be, fear-gone. // AgKs_20

## kram-p21 (21)
This earth I bind, world-fear-difference-torment-making; this knowledge-only-course-made, quickly, fluid-rasa-full, this too I make; thus binding, dissolution, conduct, as-wished, lasat, my heart. // AgKs_21

## kram-p22 (22)
Action-knowledge-sense-etc. limited-place measure gained, its spread, by own-own-taste, contracting, which; this sun's stability-place-yoked sap all, forcibly contracting, make my difference, world-fear-from. // AgKs_22

## kram-p23 (23)
Whole, unmeasured, in self, again-and-again, mass-full-mahāraśmi-nivaha; to make parā divine-bliss, by generous, rest, heart-place beautify. // AgKs_23

## kram-p24 (24)
In measure, dissolved, Śiva-pada-shining-power-vaibhava-force, body-breath-and-rest limited-made-agentness-standing; when time-condition, dissolution-state approaches you — then goddess, which, shining, my, she be Śiva-made. // AgKs_24

## kram-p25 (25)
Manifestation-named consciousness, sequenceless, from void absorbed, outside absorbed, extreme covering; thence inside-essence, by melted-rush, sequenceless; great-Time-goddess she, my, all-time making. // AgKs_25

## kram-p26 (26)
Then goddess, in which, supreme-fullness-standing-power-possessor, sequence cutting, quickly, standing-matter-rasa, makes; measure, mother, whole, world, this, standing, embracing, rest my mind, consciousness this. // AgKs_26

## kram-p27 (27)
Unobstructed-own-self-made, Maheśa, in whom, wheel-powers they; that power-possessor, I bow, god, churn-named, world-one-essence. // AgKs_27

## kram-p28 (28)
Thus own-power-ray-mass-succession, having heard, Lord, if you go to grace; by that quickly, all-folk, own-doctrine-ray, all-darkness-mass removed, make. // AgKs_28

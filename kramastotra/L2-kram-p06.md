# Kramastotra kram-p06 (unhymnable, hymned) — L2 READ

## v.6
Be — the heart holds the varied conduct of the Lord famed vast-lordly, many-powered. If so, how would hymning be done? Yet it is done — by that, suddenly. On gaining Śiva-oneness, Śiva-bowing is the first means.
The Sanskrit: *hṛdayam adhiśete yadi tataḥ | kathaṃ stotraṃ kuryād | śivaikātmyaprāptau śivanatir upāyaḥ prathamakaḥ*

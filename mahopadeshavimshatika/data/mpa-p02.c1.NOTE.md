# C1 NOTE — mpa-p02

Moved from C1 (pristine essence and SUMMARY only):

## SUMMARY

Derived waking and sleep: his waking yours, his rest yours — all of your nature, real-unreal. Rites exhausted at the start: tired tongue, tired mind — meditation with no form, name with no quality. Summoning, seating, washing, sipping questioned: each without place or receiver. Bath, garment, scent, jewel questioned: none for stainless, world-full, unanointed, lovely. Thread, flowers, incense, lamp questioned: each without a receiver. Food, betel, circling, bowing questioned: all without a needy recipient. Lights, hymn questioned: waving-lights for self-shining, hymn for unspeakable. Sending-off, oblation questioned: no going out for the full, no difference for the fire. Fee, drink, dismissal, pardon questioned: none owed where full, content, everywhere, unseen. Highest worship is nondual mind yoked to the Lord of all, in every state, always.

## VOICE MAP

Poet: derivation v11; exhaustion v12; summoning v13; adornment v14; offering v15; honorifics v16; lights v17; farewell v18; closing accounts v19; seal v20.

## KEY TERMS

* kutaḥ — whence/wherefore as the whole method
* naṭavat — actor-like, print naTavan kept
* sadasat — real-unreal as derived world
* niyojayet — let-yoke as the single imperative
* aikyabuddhi — nondual mind as the only instrument
* v15 apraṇasya variant — recorded, not built

## CRUXES

* Nineteen negations, one imperative: every rite asked away, then yoking answers all.
* The close (v20) is doctrine, not colophon: the yoking imperative is the text's only command.

## FUNCTION

Runs the kutaḥ battery across every rite, then answers all of it with one yoking.

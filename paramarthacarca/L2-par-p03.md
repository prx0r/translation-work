# paramarthacarca par-p03 — L2 READ

## v.3
Thus — dense own-consciousness, one indeed: he is Śiva, the universe's supreme light. There too, indeed, shines, in variegated power: apprehended-apprehender-division-difference.
The Sanskrit: *ittham svasaṃvidghanaḥ ekaḥ eva śivaḥ saḥ viśvasya paraḥ prakāśaḥ | tatra api bhāti eva vicitraśaktau grāhya gṛhītṛ pravibhāga bhedaḥ*

# C1 NOTE — par-p05.c1

Moved from C1 (pristine rasa-evocative translation only):

## SUMMARY

If even a common mirror shows prototype-with-reflection as mind-established, the free-consciousness mirror needs no other cause among things.

## FUNCTION

Establishes the mirror needing only mind — a fortiori.

## KEY TERMS

* **ādarśakukṣa** — mirror's belly
* **pratibimba** — reflection
* **sabimbaka** — with-prototype
* **mānasiddha** — mind-proven
* **svacchandasaṃvit** — free consciousness
* **mukura** — mirror
* **antarāla** — interior
* **hetvantara** — other cause

## LOCAL CONTEXT

The mirror needs only mind.

## EXPLANATION

If (yadi), in a mirror's belly (ādarśakukṣau), the reflection-making (pratibimbakāri) with-prototype (sabimbakam) would be (syāt) mind-proven (mānasiddham) — established by mind alone — then, in the interior (antarāle) of the mirror of free (svacchanda) consciousness (saṃvit), among things (bhāveṣu), there is (asti) no (na) other (anyat) cause besides (hetvantaram). The common mirror proves the pattern; a fortiori the free-consciousness mirror needs no second cause. Mukhura is read as mukura (mirror) — the ādarśa context requires it; print form kept in T1, reading marked here.

## BOUNDARY

Mukhura/mukura reading is an editorial decision, marked here.

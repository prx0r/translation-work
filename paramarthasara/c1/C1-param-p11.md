# C1 — param-p11

## SUMMARY

Heaven-hell-made, between bodies, fitness-yoked onward. Once-shone in knowing-time stays same past body-fall. Death-signs: senses stolen, memory lost, breath choked. Yoked yet unfallen from self-truth. Taught quickly from teacher-mouth: keen-graced, unblocked Śiva. Stepped resorting roots in truth, ends Śiva-made. Mid-way death allowed the yearning. Fallen rests a world-lord, returns Śiva next birth. Missing yoga yet rejoicing long in god-pleasures.

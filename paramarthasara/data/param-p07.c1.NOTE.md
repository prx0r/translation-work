# C1 NOTE — param-p07

Moved from C1 (pristine essence and SUMMARY only):

## SUMMARY

Done yet fruitless — how birth? Birth-bond gone, the Śiva-sun shines by its own rays. As husk-freed seed unsprouting, the freed self unbirthing. All own-formed: fearless, griefless, since perishing is not. Jewel-heaped from the heart-treasury — 'I indeed' in the Lord-state: what misfortune? Liberation has no abode, no journey: knot-cut, own-power-manifest. Knotted cut, doubted gone, delusion cast, merit wasted — bodied yet freed. As burnt seed unsprouting, burnt deed unbirthing. Limited mind, contemplating fit bodies, contracts knowing to the falling body. If again stainless knowing, all-transcending, spread, never-setting light-formed, true-resolved...

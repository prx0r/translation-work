# Transmission brief — Śivasūtra (Vasugupta's 77 sūtras)

*Root Trika tantra: 77 sūtras in three unmeṣas (1: 22 universal
consciousness / 2: 10 arising of innate knowledge / 3: 45 yogic
vibrations). Sūtra style — maximum density, commentary (Kṣemarāja's
Vimarśinī, Bhāskara's Vārttika) is support, never source. Verse ids
in this work are running ints 1–77 (span-p09 = 1.21–1.22 tail).*

## 1. WHAT IT IS

Vasugupta's Śivasūtra: the aphoristic root of Kashmir nondualism —
consciousness (caitanya) IS the self; bondage is contracted
knowledge; recognition restores vibration (spanda). Each sūtra is a
complete proposition; argmaps stay one-claim-per-sūtra, no merging.

## 2. MOVES TO LOOK FOR

1. **Definition-then-unfolding.** Unmeṣa 1 defines (caitanyam ātmā);
   everything after unpacks. Test later claims against sūtras 1–3.
2. **Bondage as contraction.** jñānaṃ bandhaḥ — bondage is limited
   knowing, never substance. Keep epistemic readings primary.
3. **Yogic operators (unmeṣa 3).** Breath/mantra/moment practices are
   means (upāya), not metaphysics — gloss as practice claims.

## 3. TRAPS

1. **Aphoristic density.** One compound = one doctrine; never pad
   with commentary content in L2.
2. **Vimarśinī/Vārttika bleed.** Kṣemarāja vs Bhāskara disagree in
   places; L0 grounds stay mūla-morphological, commentaries only
   adjudicate forks on the record.
3. **Running ids ≠ sūtra numbers.** working verse ints run 1–77;
   the `sutra` field carries 1.1–3.45. Never renumber.

## 4. APPROACH

Tiny tail work (span-p09: 2 sūtras) — single triple, exact glosses,
C1-essence names what each sūtra DOES to the bondage-claim.

**Ledger (LOCK):** caitanya = consciousness (the self); unmeṣa =
transmission-section; spanda = vibration (the return); upāya = means.

# Transmission brief — Spandakārikā (Vasugupta's Stanzas on Vibration)

*Root Trika tantra: 52 verses (Kashmir recension), three niḥṣyandas
(1–25 awakening / 26–29 powers / 30–52 practice + praśasti colophon).
Mūla only — the M00067 e-text interleaves vṛtti, ṭippaṇī and vivṛti
quotes that repeat verse numbers; never gloss a quote as mūla.*

## 1. WHAT IT IS

Vasugupta's Spandakārikā: the founding Trika statement that ultimate
reality is spanda — vibration/pulsation — the throb by which
consciousness (citi) emits and reabsorbs the world without leaving
itself. Each stanza is a compressed proof: bondage is mislocated
agency, recognition (pratyabhijñā) is the return. Dyczkowski's *Stanzas
on Vibration* is the comparative gold standard for hard verses; the
vivṛti (Kṣemarāja's lineage) is support, never source.

## 2. MOVES TO LOOK FOR

1. **Agency relocated, not denied.** Every bondage-verse argues the
   bound soul acts but misattributes the act; the argmap must keep
   agent-act-misattribution distinct in the premises.
2. **unmeṣa/nimeṣa as the engine.** Opening/closing (emergence/
   reabsorption) is the one mechanism under all three niḥṣyandas —
   test each passage's premises against it.
3. **Yogi-vs-bound contrast passages (esp. niḥṣyanda 3).** Paired
   claims about the awakened vs unawakened state; keep the pairs
   parallel in L2 or the contrast collapses.
4. **The praśasti is colophon, not doctrine.** Vasugupta's closing
   (in span-p06 tail) gets argmap-as-attribution, never as argument.

## 3. TRAPS

1. **M00067 interleaves commentary.** vṛtti/ṭippaṇī/vivṛti quote mūla
   verses out of order with repeated numbers — dedup to first mūla
   occurrence; commentary Sanskrit never enters T1/L0.
2. **Passage labels were truncated.** Fixed 2026-11-11 against mūla
   order: p01=1–6, p02=7–13, p03=14–19, p04=20–25, p05=26–29,
   p06=30–52+colophon. Trust these, not file history.
3. **spanda ≠ spandana-flutter.** Technical term: the autonomous
   throb of consciousness. Never render as emotion/trembling.
4. **citi/cit synonyms are load-bearing.** citi (consciousness-mass),
   cit (pure consciousness), jñāna (operative knowing) — gloss each
   exactly; collapsing them breaks inferences.

## 4. APPROACH

p05 (4 verses) + p06 (23 verses + colophon) remaining; p01–p04 fully
layered (L2/L3/L4 in data/). Small groups (≤12 verses given density);
gloss mūla verses against Dyczkowski where uncertain; C1-essence names
what each niḥṣyanda DOES to the bondage-claim.

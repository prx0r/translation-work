## MOVES to look for
1. Causality first (1-48): what arising MEANS before listing what arises —
   the chain rests on consciousness's free will, argued against other schools
   (weigh, don't skip, the refutations).
2. Descent ladder (49-314): Siva → Sakti → pure levels → maya → 5 kancukas →
   purusa → prakrti → buddhi → ahamkara → manas → senses/organs → tanmatras →
   elements → earth. Each rung = more contraction, same light.
3. Mala/karman/maya trilogy (61-166): impurity as covering (not stain),
   karman as residue-in-waiting (incl. Mimamsa adrsta ref), maya as Siva's own
   deluding power (night-metaphor) — three distinct bondages, three distinct
   vocabularies.
4. Kancuka mechanics (166-220): kala (limited agency), vidya (limited knowing),
   raga (attachment), kala (time), niyati (necessity) — the garb that degrades
   Siva-hood to animality; each gets definition + function + sequence-slot.
5. Pervasion close (OccultGuide): higher tattvas pervade lower by holding
   MORE qualities — earth carries all light above it. The chapter's payoff.

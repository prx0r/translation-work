# Transmission brief: Tantraloka a17 (Prameyaprakriyā, 122v)

*Assessor-authored from web scholarship, 2026-11-07. Cached per front, auto-injected into triple packets.*

## What the text IS
Ahnika 17 of Abhinavagupta's Tantraloka (KSTS ed., GRETIL `tantraloka.txt` 122 verses),
titled Prameyaprakriyā. Dyczkowski Vol 9 (ch16–27 arc): ch16 sets putraka
apprentice initiation (triple-triad mandala, Twelve Kalis, nyasa of Six Paths);
ch17 continues with the apprentice's thread (yajnopavita), purification of the
tattva-series he traverses, inner bodily illumination by mantra, burning of
fetters, conjunction (yojana) to the supreme, and fire offerings. Pradipaka
sections the flow: vv1-14 (five-locus procedure + thread-knot), 15-33, 34-51,
52-61, 62-72, 73-82, 83-90, 91-101, 102-111, 112-122. Jayaratha's commentary
reads with the verses (Dyczkowski translates both together).

## MOVES to look for
1. Five-locus frame (v1): mandala, kumbha (pot), agni, sisya, svatman — every
   rite below sits in one of these five.
2. Thread-knot exteriorizes interior bondage (vv2-6): karma/maya/anu malas mapped
   arm/throat/crest; the visible knot steadies (pratiti-dardhya) the invisible one.
3. Tattva purification in order (vv7-10): earth first by own-mantra, then the
   pervading goddess (maya-sakti) with matrka/malini syllables for
   avahana/puja respectively.
4. Uha-mantra construction (vv11-13): Tara + address + karma-verb + dipaka +
   dative name — the guru builds the operative mantra, then acts.
5. Avahana redefined (v14): awakening (sambodha) of the already-present
   I-ness, not fetching a distant deity.

## TRAPS
- `sutra-granthi`: physical thread-knot AND interior bond-knot — keep both senses,
  never collapse to one.
- `adhvan`: the path-series (tattva course), not a road; `tattva` = reality-level.
- `avahana/puja/tarpana`: technical sequence (invoke/worship/satisfy), each with
  its own mantra-syllable (matrka for avahana, malini for puja).
- `malini/matrka varna`: goddess-syllable sets, not alphabet primers.
- Numbered color triples (white/black/red thread) record variant practice
  (srutyante ke'pi) — report the variant, don't harmonize.
- Print damage: Pradipaka brackets are his completions — never treat bracketed
  English as source Sanskrit.

## APPROACH
- Scope: verse-sized units; compounds whole as source spaces them (fused-span rule).
- Gloss plainly ("thread-knot", "three impurities"), grounds from mantra-nyasa
  logic; mark genuine forks (e.g. ambiguous dative agents) with analyzed morph,
  never smooth.
- Argmap: one question per verse (the rite's own: what is done, where, with what
  mantra), premises name loci + mantra + result; uncertainties carry open
  referents (e.g. `ratisekharah`) honestly.
- Witnesses (Dyczkowski Vol 9, Pradipaka ch17, HF glossary index) are
  consistency checks only — never grounds, never hosted, never cited as source.

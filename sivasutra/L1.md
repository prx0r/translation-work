# Śivasūtra — L1 controlled

## sivs-p01 (1.1–1.10)
Caitanyam ātmā. Jñānaṃ bandhaḥ. Yonivargaḥ kalāśarīram. Jñānādhiṣṭhānaṃ mātṛkā. Udyamo bhairavaḥ. Śakticakrasaṃdhāne viśvasaṃhāraḥ. Jñānaṃ jāgrat. Svapno vikalpāḥ. Aviveko māyā sauṣuptam. Tritayabhoktā vīreśaḥ. // 1.1–1.10

## sivs-p02 (1.11–1.20)
Vismayo yogabhūmikāḥ. Icchā śaktir umā kumārī. Dṛśyaṃ śarīram. Śuddhatattvasaṃdhānād vāpaśuśaktiḥ. Vitarka ātmajñānam. Lokānandaḥ samādhisukham. Śaktisaṃdhāne śarīrotpattiḥ. Bhūtasaṃdhānabhūtapṛthaktvaviśvasaṃghaṭṭāḥ. Śuddhavidyodayāc cakreśatvasiddhiḥ. Mahāhradānusaṃdhānān mantravīryānubhavaḥ. // 1.11–1.20

## sivs-p03 (2.1–2.10)
Cittaṃ mantraḥ. Prayatnaḥ sādhakaḥ. Vidyāśarīrasattā mantrarahasyam. Garbhe cittavikāso 'viśiṣṭavidyāsvapnaḥ. Vidyāsamutthāne svābhāvike khecarī śivāvasthā. Gurur upāyaḥ. Mātṛkācakrasaṃbodhaḥ. Śarīraṃ haviḥ. Jñānam annam. Vidyāsaṃhāre tadutthasvapnadarśanam. // 2.1–2.10

## sivs-p04 (3.1–3.10)
Ātmā cittam. Jñānaṃ bandhaḥ. Kalādīnāṃ tattvānām aviveko māyā. Śarīre saṃhāraḥ kalānām. Nāḍīsaṃhārabhūtajayabhūtakaivalyabhūtapṛthaktvāni. Mohāvaraṇāt siddhiḥ. Mohajayād anantābhogāt sahajavidyājayaḥ. Jāgrad dvitīyakaraḥ. Nartaka ātmā. Raṅgo 'ntarātmā. // 3.1–3.10

## sivs-p05 (3.11–3.20)
Prekṣakāṇīndriyāṇi. Dhīvaśāt sattvasiddhiḥ. Siddhaḥ svatantrabhāvaḥ. Yathā tatra tathānyatra. Bījāvadhānam. Āsanasthaḥ sukhaṃ hrade nimajjati. Svamātrānirmāṇam āpādayati. Vidyāvināśe janmavināśaḥ. Kavargādiṣu māheśvaryādyāḥ paśumātaraḥ. Triṣu caturthaṃ tailavad āsecyam. // 3.11–3.20

## sivs-p06 (3.21–3.30)
Magnaḥ svacittena praviśet. Prāṇasamācāre samadarśanam. Madhye 'varaprasavaḥ. Mātrāsv apratyayasaṃdhāne naṣṭasya punar utthānam. Śivatulyo jāyate. Śarīravṛttir vratam. Kathā japaḥ. Dānam ātmajñānam. Yo 'vipastho jñāhetuś ca. Svaśaktipracayo viśvam. // 3.21–3.30

## sivs-p07 (3.31–3.40)
Sthitilayau. Tatpravṛttāv apy anirāsaḥ saṃvettṛbhāvāt. Sukhāsukhayor bahir mananam. Tadvimuktas tu kevalī. Mohapratisaṃhatas tu karmātmā. Bhedatiraskāre sargāntarakarmatvam. Karaṇaśaktiḥ svato 'nubhavāt. Tripadādyanuprāṇanam. Cittasthitivac charīrakaraṇabāhyeṣu. Abhilāpād bahirgatiḥ saṃvāhyasya. // 3.31–3.40

## sivs-p08 (3.41–3.45)
Tadārūḍhapramites tatkṣayāj jīvasaṃkṣayaḥ. Bhūtakañcukī tadā vimukto bhūyaḥ patisamaḥ paraḥ. Naisargikaḥ prāṇasambandhaḥ. Nāsikāntarmadhyasaṃyamāt kim atra savyāpasavyasauṣumneṣu. Bhūyaḥ syāt pratimīlanam. // 3.41–3.45

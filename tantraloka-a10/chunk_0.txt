ucyate trikaśāstrekarahasyaṃ tattvabhedanam // 1b [AbhT_10.1]
bhedāntaramapi proktaṃ śāstre@tra śrītrikābhidhe // 2 [AbhT_10.2]
bhidyate pañcadaśadhā svarūpeṇa sahānarāt // 3 [AbhT_10.3]
tadvanmāyā ca navadhā jñākalāḥ saptadhā punaḥ // 4 [AbhT_10.4]
śivo na bhidyate svaikaprakāśaghanacinmayaḥ // 5 [AbhT_10.5]
śaktimantaḥ sapta tathā śaktayastaccaturdaśa // 6 [AbhT_10.6]
tathāhi tisro devasya śaktayo varṇitāḥ purā // 7 [AbhT_10.7]
parāṃśo mātṛrūpo@tra pramāṇāṃśaḥ parāparaḥ // 8 [AbhT_10.8]
tatra svarūpaṃ bhūmeryatpṛthagjaḍamavasthitam // 9 [AbhT_10.9]
sakalādiśivāntaistu mātṛbhirvedyatāsya yā // 10 [AbhT_10.10]
sakalādiśivāntānāṃ śaktiṣūdrecitātmasu // 11 [AbhT_10.11]
sakalasya pramāṇāṃśo yo@sau vidyākalātmakaḥ // 12 [AbhT_10.12]
layākalasya mānāṃśaḥ sa eva paramasphuṭaḥ // 13 [AbhT_10.13]
aśuddhavidyākalanādhvaṃsasaṃskārasaṃgatā // 14 [AbhT_10.14]
prabuddhā śuddhavidyā tu tatsaṃskāreṇa saṃgatā // 15 [AbhT_10.15]
mānaṃ mantramaheśānāṃ karaṇaṃ śaktirucyate // 16 [AbhT_10.16]
śivasya saiva karaṇaṃ tayā vetti karoti ca // 17 [AbhT_10.17]
nyagbhūtodriktaśaktitvāttadbhedo vedyabhedakaḥ // 18 [AbhT_10.18]
caitreṇa vedyaṃ vedmīti kiṃhyatra pratibhāsatām // 19 [AbhT_10.19]
vedyatākhyastu no dharmo bhāti bhāvasya nīlavat // 20 [AbhT_10.20]

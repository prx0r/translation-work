pramātāstyeva sakalaḥ pāñcadaśyamataḥ sthitam // 101 [AbhT_10.101]
sakalāntaramastyeva prameye@trāpi mātṛ hi // 102 [AbhT_10.102]
pītādyāḥ sthirakampratvāccaturdaśa dharādiṣu // 103 [AbhT_10.103]
pramātṛtājuṣaḥ proktā dhāraṇā vijayottare // 104 [AbhT_10.104]
tadudbhūtaḥ kañcukāṃśo meyo nāsya pramātṛtā // 105 [AbhT_10.105]
trayodaśatvaṃ tacchaktiśaktimaddvayavarjanāt // 106 [AbhT_10.106]
māyāniviṣṭo vijñānākalādyāḥ prāgvadeva tu // 107 [AbhT_10.107]
so@pi meyaḥ kañcukaikyaṃ yato māyā susūkṣmikā // 108 [AbhT_10.108]
māyāniviṣṭe@pyakale tathetyekādaśātmatā // 109 [AbhT_10.109]
udbubhūṣuprabodhānāṃ mantrāṇāmeva mātṛtā // 110 [AbhT_10.110]
sa hyudbhavātpūrṇabodhastasminprāpte tu meyatām // 111 [AbhT_10.111]
tasminvijñeyatāṃ prāpte svaprakāśaḥ paraḥ śivaḥ // 112 [AbhT_10.112]
śivaḥ pramātā no meyo hyanyādhīnaprakāśatā // 113 [AbhT_10.113]
svaprakāśe@tra kasmiṃścidanabhyupagate sati // 114 [AbhT_10.114]
tataśca suptaṃ viśvaṃ syānna caivaṃ bhāsate hi tat // 115 [AbhT_10.115]
ityasya svaprakāśatve kimanyairyuktiḍambaraiḥ // 116 [AbhT_10.116]
nanvasti svaprakāśe@pi śive vedyatvamīdṛśaḥ // 117 [AbhT_10.117]
satyaṃ sa tu tathā sṛṣṭaḥ parameśena vedyatām // 118 [AbhT_10.118]
tathābhūtaśca vedyo@sau nānavacchinnasaṃvidaḥ // 119 [AbhT_10.119]
tathā vedyasvabhāve@pi vastuto na śivātmatām // 120 [AbhT_10.120]

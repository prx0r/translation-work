athādhikṛtibhāhanaṃ ka iha vā kathaṃ vetyalaṃ vivecayitumucyate vividhaśaktipātakramaḥ // 1b [AbhT_13.1]
taṃ pradarśya nirākṛtya svamataṃ darśayiṣyate // 2 [AbhT_13.2]
viṣamaṃ sattathābhūtaṃ samaṃ hetuṃ prakalpayet // 3 [AbhT_13.3]
ghaṭādivatkāryamiti hetureko@sya sā niśā // 4 [AbhT_13.4]
kalādidharaṇīprāntaṃ jāḍyātsā sūtaye@kṣamā // 5 [AbhT_13.5]
puṃsaḥ prati ca sā bhogyaṃ sūte@nādīn pṛthagvidhān // 6 [AbhT_13.6]
nimittaṃ karmasaṃskāraḥ sa ca teṣu na vidyate // 7 [AbhT_13.7]
na bhogādanyakarmāṃśaprasaṅgo hi duratyayaḥ // 8 [AbhT_13.8]
phaledyatkarma tatkasmātsvaṃ rūpaṃ saṃtyajetkvacit // 9 [AbhT_13.9]
dharmādyadi kutaḥ so@pi karmataścettaducyatām // 10 [AbhT_13.10]
karmajatve ca tajjñānaṃ phalarāśau pateddhruvam // 11 [AbhT_13.11]
īśasya dveṣarāgādiśūnyasyāpi kathaṃ kvacit // 12 [AbhT_13.12]
nanvitthaṃ pradahejjñānaṃ karmajālāni karma hi // 13 [AbhT_13.13]
ajñānaṃ jñānato naśyedanyakarmaphalādapi // 14 [AbhT_13.14]
niṣphalīkurute duṣṭaṃ karmetyaṅgīkṛtaṃ kila // 15 [AbhT_13.15]
prāgabhāvo@thavā dhvaṃsa ādye kiṃ sarvasaṃvidām // 16 [AbhT_13.16]
na kiṃcidyasya vijñānamudapādi tathāvidhaḥ // 17 [AbhT_13.17]
bhāvinaḥ prāgabhāvaśca jñānasyeti sthite sati // 18 [AbhT_13.18]
jñānaṃ bhāvi vimukte@sminniti ceccarcyatāmidam // 19 [AbhT_13.19]
tatkasmātkarmaṇaḥ kṣaiṇyāttatkuto@jñānahānitaḥ // 20 [AbhT_13.20]

ullaṅghanavaśādvāpi jhaṭityakramameva vā // 301 [AbhT_13.301]
gururullaṅghitādhaḥsthasrotā vai trikaśāstragaḥ // 302 [AbhT_13.302]
śāstreṣvadīdṛśacchrīmatsarvācārahṛdādiṣu // 303 [AbhT_13.303]
tathāpi bhairave tantre punaḥ saṃskāramarhati // 304 [AbhT_13.304]
sarve te paśavo jñeyā bhairave mātṛmaṇḍale // 305 [AbhT_13.305]
bhasmaniṣṭhāprapannānāmityādau naiva yogyatā // 306 [AbhT_13.306]
anyaśāstrarato yastu nāsau siddhiphalapradaḥ // 307 [AbhT_13.307]
sa ca śaktivaśāditthaṃ vaiṣṇavādiṣu ko@nvayaḥ // 308 [AbhT_13.308]
prāyaścittamatastādṛgadhikāryatra kiṃ bhavet // 309 [AbhT_13.309]
dhruvaṃ pacyeta narake prāyaścittyupasevanāt // 310 [AbhT_13.310]
gurau śivena tadbhaktiḥ śaktipāto@sya nocyate // 311 [AbhT_13.311]
viparītapravṛttatvaṃ jñānaṃ tasmādupāharet // 312 [AbhT_13.312]
yathā caurādgṛhītvārthaṃ taṃ nigṛhṇāti bhūpatiḥ // 313 [AbhT_13.313]
sa hi bhedaikavṛttitvaṃ śivajñāne śrute@pyalam // 314 [AbhT_13.314]
śivenaiva tirobhāvya sthāpito niyaterbalāt // 315 [AbhT_13.315]
svacchandaśāstre proktaṃ ca vaiṣṇavādiṣu ye ratāḥ // 316 [AbhT_13.316]
vaiṣṇavādiḥ śaivaśāstraṃ melayannijaśāsane // 317 [AbhT_13.317]
svadṛṣṭau paradṛṣṭau ca samayollaṅghanādasau // 318 [AbhT_13.318]
uktaṃ śrīmadgahvare ca parameśena tādṛśam // 319 [AbhT_13.319]
tanna saiddhāntiko vāme nāsau dakṣe sa no mate // 320 [AbhT_13.320]

## tal-a14-p03 (14.21-14.30)
[and]-bhūyo@nugrahataḥ prāyaścittādyācaraṇe sati / anusāreṇa dīkṣādau kṛte syācchivatāmayaḥ tirobhūtaḥ paretāsurapi bandhusuhṛdgurūn / ālambya śaktipātena dīkṣādyairanugṛhyate tatrāpi kālaśīghratvaciratvādivibhedatām / tathaiti śaktipāto@sau yenāyāti śivātmatām itthaṃ sṛṣṭisthitidhvaṃsatirobhāvamanugrahaḥ / iti pañcasu kartṛtvaṃ śivatvaṃ saṃvidātmanaḥ pañcakṛtyasvatantratvasaṃpūrṇasvātmamāninaḥ / yogino@rcājapadhyānayogāḥ saṃsyuḥ sadoditāḥ aindrajālikavṛttānte na rajyeta kadācana / sādāśivo@pi yo bhogo bandhaḥ so@pyucitātmanām jñātṛtvameva śivatā svātantryaṃ tadihocyate / kulālavattu kartṛtvaṃ na mukhyaṃ tadadhiṣṭhiteḥ iti jñātvā grahītavyā naiva jātvapi khaṇḍanā / śivo@haṃ cenmadicchānuvarti kiṃ na jagattviti mamecchāmanuvartantāmityatrāhaṃvidi sphuret / śivo vā parameśāno dehādiratha nirmitaḥ śivasya tāvadastyetaddehastveṣa tathā tvayā / kṛtaḥ kānyā dehatāsya tatkiṃ syādvācyatāpadam

## tal-a14-p04 (14.31-14.40)
[and]-uktaṃ ca siddhasantānaśrīmadūrmimahākule / pavanabhramaṇaprāṇavikṣepādikṛtaśramāḥ kuhakādiṣu ye bhrāntāste bhrāntāḥ parame pade / sarvatra bahumānena yāpyutkrāntirvimuktaye proktā sā sāraśāstreṣu bhogopāyatayoditā / yadi sarvagatā devo vadotkramya kva yāsyati athāsarvagatastarhi ghaṭatulyastadā bhavet / utkrāntividhiyogo@yamekadeśena kathyate niraṃśe śivatattve tu kathamutkrāntisaṃgatiḥ / yathā dharādau vāyvante bhṛgvambvagnyupavāsakaiḥ ātmano yojanaṃ vyomni tadvadutkrāntivartanā / tasmānnotkramayejjīvaṃ paratattvasamīhayā śrīpūrvaśāstre tūktaṃ yadutkrānterlakṣaṇaṃ na tat / muktyupāyatayā kiṃtu bhogahānyai tathaiṣaṇāt japadhyānādisaṃsiddhaḥ svātantryācchaktipātataḥ / bhogaṃ prati viraktaśceditthaṃ dehaṃ tyajediti svacchandamṛtyorapi yad bhīṣmādeḥ śrūyate kila / bhogavairasyasaṃprāptau jīvitāntopasarpaṇam yogamantrāmṛtadravyavarādyaiḥ siddhibhāktanuḥ / hātuṃ nahyanyathā śakyā vinoktakramayogataḥ

## tal-a14-p05 (14.41-14.47)
[and]-uktaṃ ca mālinītantre parameśena tādṛśam / sarvamapyathavā bhogaṃ manyamāno virūpakam ityādi vadatā sarvairalakṣyāntaḥsatattvakam / evaṃ sṛṣṭyādikartavyasvasvātantryopadeśanam yatsaiva mukhyadīkṣā syācchiṣyasya śivadāyinī / uktaṃ śrīniśicāre ca bhairavīyeṇa tejasā vyāptaṃ viśvaṃ prapaśyanti vikalpojjhitacetasaḥ / vikalpayuktacittastu piṇḍapātācchivaṃ vrajet bāhyadīkṣādiyogena caryāsamayakalpanaiḥ / avikalpastathādyaiva jīvanmukto na saṃśayaḥ saṃsārajīrṇatarumūlakalāpakalpasaṃkalpasāntaratayā paramārthavahneḥ / syurvisphuliṅgakaṇikā api cettadante dedīpyate vimalabodhahutāśarāśiḥ itthaṃ dīkṣopakramo@yaṃ darśitaḥ śāstrasaṃmataḥ / [AbhT_14.47]

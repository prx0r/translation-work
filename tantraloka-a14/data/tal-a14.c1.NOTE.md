# C1 NOTE — tal-a14 (not the translation: commentary complete)

## KEY TERMS (with grounds)

- tirobhāva (m.): concealment, the Lord's fourth act; charter word (v1, v17–v19).
- niyati-aniyati-krama (m.): rule-bound and rule-free order both touched (v1).
- svacchanda (m.): self-willed; named from shining-while-touching (v2).
- avāntara-sṛṣṭi/sthiti (f.): intermediate creation; unforced stasis (v3–v4).
- svarūpa-ācchādana-krama (m.): self-concealing procedure re-admitting niyati (v5).
- karma-phala-krama (m.): fruit-order binding only under kept restraint (v6).
- pratibuddha-abuddhavat / anuttīrṇa-uttīrṇavat: awakened-as-unawakened theater (v7–8).
- mānastotra (n.): Vidyādhva's dissent similes — sun/lotus, snake-fat lamp, lead-copper, undrunk nectar (v9–12).
- dāha-śaṅkā (f.): burning doubt kindled inwardly (v13).
- parameśa-icchā-moha (m.): will-delusion into suffering-vesselhood (v15–v17).
- samayollaṅghana-tirobhāva (m.): second concealment; kravyādatva 100 years, graded (v18–v19).
- para-dvāra / punar-dīkṣā: return by self/other; expiation + re-initiation restores (v20–v21).
- paretāsu-anugraha (m.): post-mortem grace via kin, teachers, śaktipāta (v22–v23).
- pañca-kṛtya-kartṛtva (n.): five-act doership = Śiva-hood (v24–v25).
- aindrajālika (adj.): magic-shows shunned; Sadāśiva-bliss binds unfit (v26).
- jñātṛtva (n.): knowerness over potter-doership, superintended (v27).
- akhaṇḍanā (f.): no refutation; doubt quoted unanswered (v28).
- ahaṃvidi sphuraṇa (n.): flashing will in the I-knower (v29).
- avācyatā-pada (n.): unspeakable body-proof (v30).
- siddhasantāna-ūrmi-mahākula (wind-toiling toilers, v31).
- utkrānti-vidhiyoga (m.): departure-rite, partial; God-everywhere paradox (v32–v34).
- niraṃśa śivatattva (partless, departure-unfitting; cliff-water-fire fasts, v35).
- paratattva-samīhā (f.): longing-ejection forbidden (v36).
- pūrvaśāstra-lakṣaṇa (departure defined as enjoyment-loss, v37).
- virakta-deha-tyāga (detached leaving permitted, v38).
- svacchanda-mṛtyu (Bhīṣma precedent, v39).
- siddhi-tanu (unsheddable except by sequence, v40).
- virūpa-bhoga (ugly-enjoyment, Mālinītantra, v41).
- antaḥ-sat-tattva (unseen inner reality; provisional split, v42).
- mukhya-dīkṣā (freedom-teaching, Bhairavī-radiant, v43).
- vikalpa-ujjhita/yukta (thought-free beholding vs death-reaching, v44).
- jīvanmukti (now, no doubt, v45).
- vimala-bodha-hutāśa (pure-awakening fire-mass from burnt world-tree, v46).
- dīkṣopakrama (colophon seal, v47).

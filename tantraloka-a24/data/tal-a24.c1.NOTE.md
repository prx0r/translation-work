# C1 NOTE — tal-a24 (not the translation: commentary complete)

## KEY TERMS (with grounds)

- antyeṣṭidīkṣā (f.): funerary initiation; charter word (v1–v4).
- antyasaṃskriyā (f.): final sacrament; announced with secrecy (v1).
- śaktipāta (m.): descent gating the rite for all stations (v2).
- samayopahatātman (m.): samaya-struck self; upper-teaching violators (v3).
- pramāda (m.): negligence; stumblers covered by Dīkṣottara (v4).
- mṛtoddhāra (m.): corpse-uplifting; image-rite transferred to corpse-body (v5).
- ādi-anta-viparaya (m.): last-first reversal; Siddhātantra rule (v6).
- dvitayī saṃhṛti (f.): twofold withdrawal of oblations; bathed sādhaka eased (v7).
- piṇḍapāta (m.): body's fall; release or sky-roving follows (v8); priye vocative = Goddess.
- tattvasaṃpanna ācārya (m.): ripe teacher; place-freed (v8).
- śuddhacetas (m.): pure-minded; rite-exempt (head-synecdoche, flagged) (v9).
- atikṛpālu guru (m.): ultra-compassionate rescuer of hell-bound (v10); śmaśāna sheds maṇḍala.
- pretasadman (n.): mortuary; strict full-nyāsa school (v11); vibhu = Omnipresent.
- saṃhārakrama (m.): dissolution-sequence awakening foot-to-head (v12).
- bindu-rodha / śaktibīja-vedha / nāda-ghaṭṭa / triśūla-tāḍa: four forcible openings (v13).
- suṣumnā-visarga (m.): inner emission beating kalās; kampate paśuḥ as sign (v14).
- vāmahasta-utkṣepa (m.): left-hand raising; para-yojana follows (v15).
- kulagahvara-niyama (m.): signs build trust, never cause release (v16; negation-scope flagged).
- anumeya mokṣa (m.): inferred liberation for the supersensible (v17).
- puryaṣṭakārpaṇa (n.): eightfold-city-class offering (v17).
- śrutipatra-abja (n.): ear-petal lotus diagram; petal-term flagged (v18).
- sāṃnyāsikī dīkṣā (f.): renunciate initiation cleansing puryaṣṭaka (v20).
- mādhavakula-niṣedha (m.): no piṇḍa-water-tears even for dead (v22; catalogue flagged).
- memorial catalogue v23: split provisional (Yogawiki: e-text sequence unclear).

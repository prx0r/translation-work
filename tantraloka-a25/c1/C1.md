# C1 — Tantrāloka Ahnika 25

## tal-a25-p01–p03 — ahnika 25
**SUMMARY.** Tantrāloka Ahnika 25: [and]-:C25 atha śrītantrāloke pañcaviṃśatitamamāhnikam atha śrāddhavidhiḥ śrīmatṣaḍardhokto nigadyate siddhātantre sūcito@sau mūrtiyāganirūpaṇe / antyeṣṭyā bubhukṣostu kriyābhyāsabhūmānau phalabhūmani / hetu tato mṛtoddhāraśrāddhādyasmai samācaret tattvajñānārkavidhvastadhvāntasya tu na ko@pyayam / antyeṣṭiśrāddhavidhyādirupayogī kadācana [and]-teṣāṃ tu guru tadvargavargyasabrahmacāriṇām / tatsantānajuṣāmaikyadinaṃ parvadinaṃ bhavet yadāhi bodhasyodrekastadā parvāha pūraṇāt / janmaikyadivasau tena parvaṇī bodhasiddhitaḥ putrako@pi yadā kasmaicana syādupakārakaḥ / tadā mātuḥ pituḥ śaktervāmadakṣāntarālagāḥ nāḍīḥ pravāhayeddevāyārpayeta niveditam / śrīmadbharuṇatantre ca tacchivena nirūpitam tadvāhakālāpekṣā ca kāryā tadrūpasiddhaye / svācchandyenātha tatsiddhiṃ vidhinā bhāvinā caret yasya kasyāpi vā śrāddhe gurudevāgnitarpaṇam / sacakreṣṭi bhavecchrauto natu syātpāśavo vidhiḥ śrīmaukuṭe tathā coktaṃ śivaśāstre sthito@pi yaḥ / pratyeti vaidike bhagnaghaṇṭāvanna sa kiṃcana tathoktadevapūjādicakrayāgāntakarmaṇā / rudratvametyasau janturbhogāndivyānsamaśnute atha vacmaḥ sphuṭaṃ śrīmatsiddhaye nāḍicāraṇam / yā vāhayitumiṣyeta nāḍī tāmeva bhāvayet bhāvanātanmayībhāve sā nāḍī vahati sphuṭam / yadvā vāhayituṃ yeṣṭā tadaṅgaṃ tena pāṇinā [and]-āpīḍya kukṣiṃ namayetsā vahennāḍikā kṣaṇāt / evaṃ śrāddhamukhenāpi bhogamokṣobhayasthitim kuryāditi śivenoktaṃ tatra tatra kṛpālunā / śaktipātodaye jantoryenopāyena daiśikaḥ karotyuddharaṇaṃ tattannirvāṇāyāsya kalpate / uddhartā devadevo hi sa cācintyaprabhāvakaḥ upāyaṃ gurudīkṣādidvāramātreṇa saṃśrayet / uktaṃ śrīmanmataṅgākhye munipraśnādanantaram muktirvivekāttattvānāṃ dīkṣāto yogato yadi / caryāmātrātkathaṃ sā syādityataḥ samamuttaram prahasyoce vibhuḥ kasmādbhrāntiste parameśituḥ / sarvānugrāhakatvaṃ hi saṃsiddhaṃ dṛśyatāṃ kila prāptamṛtyorviṣavyādhiśastrādi kila kāraṇam / alpaṃ vā bahu vā tadvadanudhyā muktikāraṇam muktyarthamupacaryante bāhyaliṅgānyamūni tu / iti jñātvā na sandeha itthaṃ kāryo vipaścitā iyataiva kathaṃ muktiriti bhaktiṃ parāṃ śrayet / uktaḥ śrāddhavidhirbhrāntigarātaṅkavimardanaḥ

## tal-a26-p01 (26.1-26.10)
[and]-:C26 atha śrītantrāloke ṣaḍviṃśamāhnikam athocyate śeṣavṛttirjīvatāmupayoginī dīkṣā bahuprakāreyaṃ śrāddhāntā yā prakīrtitā / sā saṃskriyāyai mokṣāya bhogāyāpi dvayāya vā tatra saṃskārasiddhyai yā dīkṣā sākṣānna mocanī / anusaṃdhivaśādyā ca sākṣānmoktrī sabījikā tayobhayyā dīkṣitā ye teṣāmājīvavartanam / vaktavyaṃ putrakādīnāṃ tanmayatvaprasiddhaye bubhukṣorvā mumukṣorvā svasaṃvidguruśāstrataḥ / pramāṇādyā saṃskriyāyai dīkṣā hi guruṇā kṛtā tataḥ sa saṃskṛtaṃ yogyaṃ jñātvātmānaṃ svaśāsane / taduktavastvanuṣṭhānaṃ bhuktyai muktyai ca sevate ācāryapratyayādeva yo@pi syādbhuktimuktibhāk / tatpratyūhodayadhvastyai brūyāttasyāpi vartanam svasaṃvidgurusaṃvittyostulyapratyayabhāgapi / śeṣavṛttyā samādeśyastadvighnādipraśāntaye yaḥ sarvathā parāpekṣāmujjhitvā tu sthito nijāt / pratyayādyo@pi cācāryapratyayādeva kevalāt tau sāṃsiddhikanirbījau ko vadeccheṣavṛttaye / kramāttanmayatopāyagurvarcanaratau tu tau

## tal-a26-p02 (26.11-26.20)
[and]-tatraiṣāṃ śeṣavṛttyarthaṃ nityanaimittike dhruve / kāmyavarjaṃ yataḥ kāmāścitrāścitrābhyupāyakāḥ tatra nityo vidhiḥ sandhyānuṣṭhānaṃ devatāvraje / gurvagniśāstrasahite pūjā bhūtadayetyayam naimittikastu sarveṣāṃ parvaṇāṃ pūjanaṃ japaḥ / viśeṣavaśataḥ kiṃca pavitrakavidhikramaḥ ācāryasya ca dīkṣeyaṃ bahubhedā vivecitā / vyākhyādikaṃ ca tattasyādhikaṃ naimittikaṃ dhruvam tatrādau śiśave vrūyādgururnityavidhiṃ sphuṭam / tadyogyatāṃ samālokya vitatāvitatātmanām mukhyetarādimantrāṇāṃ vīryavyāptyādiyogyatām / dṛṣṭvā śiṣye tamevāsmai mūlamantraṃ samarpayet tacchāstradīkṣito hyeṣa niryantrācāraśaṅkitaḥ / na mukhye yogya ityanyasevātaḥ syāttu yogyatā sādhakasya bubhukṣostu sādhakībhāvino@pivā / puṣpapātavaśātsiddho mantro@rpyaḥ sādhyasiddhaye vitate guṇabhūte vā vidhau diṣṭe punarguruḥ / jñātvāsmai yogyatāṃ sāraṃ saṃkṣiptaṃ vidhimācaret tatraiṣa niyamo yadyanmāntraṃ rūpaṃ na tadguruḥ / likhitvā prathayecchiṣye viśeṣādūrdhvaśāsane

## tal-a26-p03 (26.21-26.30)
[and]-mantrā varṇātmakāste ca parāmarśātmakāḥ saca / gurusaṃvidabhinnaśvetsaṃkrāmetsā tataḥ śiśau lipisthitastu yo mantro nirvīryaḥ so@tra kalpitaḥ / saṃketabalato nāsya pustakātprathate mahaḥ pustakādhītavidyāścetyuktaṃ siddhāmate tataḥ / ye tu pustakalabdhe@pi mantre vīryaṃ prajānate te bhairavīyasaṃskārāḥ proktāḥ sāṃsiddhikā iti / iti jñātvā guruḥ samyak paramānandaghūrṇitaḥ tādṛśe tādṛśe dhāmni pūjayitvā vidhiṃ caret / yathānyaśiṣyānuṣṭhānaṃ nānyaśiṣyeṇa budhyate tathā kuryādgururguptihānirdoṣavatī yataḥ / devīnāṃ tritayaṃ śuddhaṃ yadvā yāmalayogataḥ devīmekāmatho śuddhāṃ vadedvā yāmalātmikām / tatra mantraṃ sphuṭaṃ vaktrādguruṇopāṃśu coditam avadhāryā pravṛttestamabhyasyenmanasā svayam / tataḥ suśikṣitāṃ sthānadehāntaḥśodhanatrayīm nyāsaṃ dhyānaṃ japaṃ mudrāṃ pūjāṃ kuryātprayatnataḥ / tatra prabhāte saṃbudhya sveṣṭāṃ prāgdevatāṃ smaret kṛtāvaśyakakartavyaḥ śuddho bhūtvā tato gṛham / āśrityottaradigvaktraḥ sthānadehāntaratraye

## tal-a26-p04 (26.31-26.40)
[and]-śuddhiṃ vidhāya mantrāṇāṃ yathāsthānaṃ niveśanam / mudrāpradarśanaṃ dhyānaṃ bhedābhedasvarūpataḥ dehāsudhīvyomabhūṣu manasā tatra cārcanam / japaṃ cātra yathāśakti devāyaitannivedanam tanmayībhāvasiddhyarthaṃ pratisandhyaṃ samācaret / anye tu prāgudakpaścāddaśadikṣu catuṣṭayīm sandhyānāmāhuretacca tāntrikīyaṃ na no matam / yāsau kālādhikāre prāk sandhyā proktā catuṣṭayī tāmevāntaḥ samādhāya sāndhyaṃ vidhimupācaret / sandhyācatuṣṭayīkṛtyamekasyāmathavā śiśuḥ kuryātsvādhyāyavijñānagurukṛtyāditatparaḥ / sandhyādhyānoditānantatanmayībhāvayuktitaḥ tatsaṃskāravaśātsarvaṃ kālaṃ syāttanmayo hyasau / tato yatheṣṭakāle@sau pūjāṃ puṣpāsavādibhiḥ sthaṇḍilādau śiśuḥ kuryādvibhavādyanurūpataḥ / suśuddhaḥ sanvidhiṃ sarvaṃ kṛtvāntarajapāntakam arghapātraṃ purā yadvadvidhāya sveṣṭamantrataḥ / tena sthaṇḍilapuṣpādi sarvaṃ saṃprokṣayedbudhaḥ tatastatraiva saṃkalpya dvārāsanagurukramam / pūjayecchivatāviṣṭaḥ svadehārcāpuraḥsaram

## tal-a26-p05 (26.41-26.50)
[and]-tatastatsthaṇḍilaṃ vīdhravyomasphaṭikanirmalam / bodhātmakaṃ samālokya tatra svaṃ devatāgaṇam pratibimbatayā paśyedbimbatvena ca bodhataḥ / etadāvāhanaṃ mukhyaṃ vyajanānmarutāmiva sarvago@pi marudyadvadvyajanenopajīvitaḥ / arthakṛtsarvagaṃ mantracakraṃ rūḍhestathā bhavet catuṣkapañcāśikayā tadetattattvamucyate / śrīnirmaryādaśāstre ca tadetadvibhunoditam devaḥ sarvagato deva nirmaryādaḥ kathaṃ śivaḥ / āvāhyate kṣamyate vetyevaṃpṛṣṭo@bravīdvibhuḥ vāsanāvāhyate devi vāsanā ca visṛjyate / paramārthena devasya nāvāhanavisarjane āvāhito mayā devaḥ sthaṇḍile ca pratiṣṭhitaḥ / pūjitaḥ stuta ityevaṃ hṛṣṭvā devaṃ visarjayet prāṇināmaprabuddhānāṃ santoṣajananāya vai / āvāhanādikaṃ teṣāṃ pravṛttiḥ kathamanyathā kālena tu vijānanti pravṛttāḥ patiśāsane / anukrameṇa devasya prāptiṃ bhuvanapūrvikām jñānadīpadyutidhvastasamastājñānasañcayāḥ / kuto vānīyate devaḥ kutra vā nīyate@pi saḥ

## tal-a26-p06 (26.51-26.60)
[and]-sthūlasūkṣmādibhedena sa hi sarvatra saṃsthitaḥ / āvāhite mantragaṇe puṣpāsavanivedanaiḥ dhūpaiśca tarpaṇaṃ kāryaṃ śraddhābhaktibalocitaiḥ / dīptānāṃ śaktinādādimantrāṇāmāsavaiḥ palaiḥ raktaiḥ prāk tarpaṇa paścāt puṣpadhūpādivistaraiḥ / āgatasya tu mantrasya na kuryāttarpaṇaṃ yadi haratyardhaśarīraṃ sa ityuktaṃ kila śambhunā / yadyadevāsya manasi vikāsitvaṃ prayacchati tenaiva kuryātpūjāṃ sa iti śambhorviniścayaḥ / sādhakānāṃ bubhukṣūṇāṃ vidhirniyatiyantritaḥ mumukṣūṇāṃ tattvavidāṃ sa eva tu nirargalaḥ / kārye viśeṣamādhitsurviśiṣṭaṃ kāraṇaṃ spṛśet raktakarpāsatūlecchustulyatadbījapuñjavat / santi bhoge viśeṣāśca vicitrāḥ kāraṇeritāḥ deśakālānusandhānaguṇadravyakriyādibhiḥ / svalpā kriyā bhūyasī vā hṛdayāhlādadāyibhiḥ bāhyaiḥ saṃkalpajairvāpi kārakaiḥ parikalpitā / mumukṣorna viśeṣāya naiḥśreyasavidhiṃ prati nahi brahmaṇi śaṃsanti bāhulyālpatvadurdaśāḥ / citaḥ svātantryasāratvāt tasyānandaghanatvataḥ

## tal-a26-p07 (26.61-26.70)
[and]-kriyā syāttanmayībhūtyai hṛdayāhlādadāyibhiḥ / śivābhedabharādbhāvavargaḥ ścyotati yaṃ rasam tameva parame dhāmni pūjanāyārpayedbudhaḥ / stotreṣu bahudhā caitanmayā proktaṃ nijāhnike adhiśayya pāramārthikabhāvaprasaraprakāśamullasati / yā paramāmṛtadṛk tvāṃ tayārcayante rahasyavidaḥ kṛtvādhāradharāṃ camatkṛtirasaprokṣākṣaṇakṣālitāmāttairmānasataḥ svabhāvakusumaiḥ svāmodasandohibhiḥ / ānandāmṛtanirbharasvahṛdayānarghārghapātrakramāt tvāṃ devyā saha dehadevasadane devārcaye@harniśam nānāsvādarasāmimāṃ trijagatīṃ hṛccakrayantrārpitāmūrdhvādhyastavivekagauravabharānniṣpīḍya niḥṣyanditam / yatsaṃvitparamāmṛtaṃ mṛtijarājanmāpahaṃ jṛmbhate tena tvāṃ haviṣā pareṇa parame saṃtarpaye@harniśam iti ślokatrayopāttamarthamantarvibhāvayan / yena kenāpi bhāvena tarpayeddevatāgaṇam mudrāṃ pradarśayetpaścānmanasā vāpi yogataḥ / vacasā mantrayogena vapuṣā saṃniveśataḥ kṛtvā japaṃ tataḥ sarvaṃ devatāyai samarpayet / taccoktaṃ kartṛtātattvanirūpaṇavidhau purā tato visarjanaṃ kāryaṃ bodhaikātmyaprayogataḥ / kṛtvā vā vahnigāṃ mantratṛptiṃ proktavidhānataḥ dvārapīṭhaguruvrātasamarpitanivedanāt / ṛte@nyatsvayamaśnīyādagādhe@mbhasyatha kṣipet

## tal-a26-p08 (26.71-26.76)

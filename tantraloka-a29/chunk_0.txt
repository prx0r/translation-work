atha sarvāpyupāseyaṃ kulaprakriyayocyate // 1 [AbhT_29.1]
uktaṃ ca parameśena sāratvaṃ kramapūjane // 2 [AbhT_29.2]
na tadvarṣasahasraiḥ syānmantraughairvividhairiti // 3 [AbhT_29.3]
svātantryamojo vīryaṃ ca piṇḍaḥ saṃviccharīrakam // 4 [AbhT_29.4]
dhvastaśaṅkāsamūhasya yāgastādṛśa eva saḥ // 5 [AbhT_29.5]
yadyatsamācaredvīraḥ kulayāgaḥ sa sa smṛtaḥ // 6 [AbhT_29.6]
iti ṣoḍhā kulejyā syātpratibhedaṃ vibhedinī // 7 [AbhT_29.7]
kiñcidatropayujyeta kṛtaṃ vā khaṇḍanāya no // 8 [AbhT_29.8]
jñānajñeyamayaṃ kaulaṃ proktaṃ traiśirase mate // 9 [AbhT_29.9]
tadeva yojayeddhīmānvāmāmṛtapariplutam // 10 [AbhT_29.10]
tāṃ vinā bhuktimuktī no piṣṭakṣaudraguḍaistu sā // 11 [AbhT_29.11]
drākṣotthaṃ tu paraṃ tejo bhairavaṃ kalpanojjhitam // 12 [AbhT_29.12]
devatānāṃ priyaṃ nityaṃ tasmādetatpivetsadā // 13 [AbhT_29.13]
arghapātraṃ yāgadhāma dīpa ityucyate trayam // 14 [AbhT_29.14]
bhūvastrakāyapīṭhākhyaṃ dhāma cotkarṣabhāk kramāt // 15 [AbhT_29.15]
iti jñātvā traye@muṣminyatnavānkauliko bhavet // 16 [AbhT_29.16]
yānyuktānyaviśaṅko@tra bhavecchaṅkā hi dūṣikā // 17 [AbhT_29.17]
parayā vā@tha mālinyā vilomāccānulomataḥ // 18 [AbhT_29.18]
krameṇa kuryādathavā mātṛsadbhāvamantrataḥ // 19 [AbhT_29.19]
tataḥ saṃśodhyavastūni śaktyaivāmṛtatāṃ nayet // 20 [AbhT_29.20]
